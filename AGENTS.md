# Agent Instructions

Godot 4.7 project, GDScript.

## Comments

Keep them short. Comment what isn't obvious from reading the code — never restate
the name, the type, or the default.

- Prefer no comment over a redundant one.
- `##` doc comments on exports only when the name alone is ambiguous.
- One line where one line does. No multi-paragraph explanations in source files.
